# Official LDraw geometry cache

Files in `parts/` and `p/` are downloaded unmodified from the official LDraw Parts Library at https://library.ldraw.org/library/official/ by `scripts/fetch_parts.py`.

The official library agreement is included in `CAreadme.txt`; the CC BY 4.0 legal text is in `CAlicense4.txt`. Both are downloaded unmodified from the same official library root.

Each source file retains its original author and license header. `manifest.json` records the precise public source URL, SHA-256 checksum, and license header for each cached file. These geometry files are licensed under the license specified in each file (typically CC BY 4.0 or CC BY 2.0); see https://creativecommons.org/licenses/by/4.0/ and https://creativecommons.org/licenses/by/2.0/.
